# 💻 COMMANDS.TXT FORMAT

Commands ko device-wise organize kiya gaya hai.

```text

                ROUTER R1


enable
configure terminal

interface gigabitEthernet 0/0
ip address 192.168.10.1 255.255.255.0
no shutdown
exit

end
write memory
```

> 💡 Is format se clearly pata chalta hai ki **kaunsi command kis device par configure ki gayi hai aur uska purpose kya hai.**
