LAB 33
Configure DHCP Relay Agent on Cisco Multilayer Switch



######Multilayer Switch Configuration ############

enable

configure terminal

interface GigabitEthernet1/0/1
no switchport
ip address 192.168.11.1 255.255.255.0
no shutdown
exit

interface GigabitEthernet1/0/2
no switchport
ip address 192.168.22.1 255.255.255.0
exit
do write



#### DHCP CONFIG ###
int gig1/0/2
ip helper-address 192.168.11.254
no shutdown
exit

ip routing

end

write memory
